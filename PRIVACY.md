# Ledger Privacy Policy (draft)

especially if you add online features later._

Ledger is a practice stock-trading game that uses pretend money. It is designed for children and teens.

## What Ledger stores

When a player makes an account, Ledger saves on **their own computer only**:

- a username (filtered so it can't contain personal info like phone numbers or websites)
- the password, stored only as a scrambled (salted scrypt) hash
- birth year, used only to decide whether a parent needs to set up the account
- for players under 13: a parent's 4-digit PIN (hashed) and the date the parent agreed
- the trader's look, game progress, trades, lessons and settings

If the player uses **Sign in with Google**, Ledger receives the Google account ID and display name
to link the account. It does **not** store the email address.

## What Ledger does not do

- It doesn't send game data to any server. There is no Ledger server.
- No ads, no in-app purchases, no chat, no tracking or analytics.
- No real money is involved, and nothing in Ledger is financial advice.

## Children under 13

New players under 13 can only create an account after a parent or guardian sets a Parent PIN and
confirms consent on the device. The PIN protects Parent View, the daily time limit and password resets.

## Friends

Friend requests and leaderboards only work between accounts on the same computer. Players can
decline, remove or block other players.

## Your choices

- **See your data:** Settings → Download my data saves a copy to your Downloads folder.
- **Delete your data:** Settings → Delete my account permanently erases the account from this computer.
- Uninstalling Ledger and deleting its data folder removes everything (see README for the location).
